## Хөшүүрэг ба явц
1. Dialect засвар — boolean баганыг `= 0/1` → `FALSE/TRUE` (D2-ийн 31 гүйцэтгэлийн алдаа). `pipeline/dialect.py`
   `_bool_literal`, `Pipeline.bool_cols()`. Явц: D2 fix Vast дээр тестлэгдэж байна.
2. Асуултыг англи руу орчуулах (A4 кэш, `--set translate=true`) — D2 tr, B5 tr. Явц: Vast.
3. Гүйцэтгэлийн алдаагаар засах (E1) ба 8 хувилбарын санал хураалт (E2). Явц: Vast (1, 2-ын шилдэг дээр).
4. Agent-уудын тайлан (логик шалгалт, алдааны ангилал) → нэмэлт ерөнхий засвар.
5. Дараагийн алхам (GPU шаардлагатай, дараа сарын Modal кредит эсвэл Kaggle):
   - E2-ийг test дээр ажиллуулж 40%-ийг баталгаажуулах (A100 дээр ~25 мин; T4 дээр удаан).
   - D2-ийг дахин сургах: RAG prompt-ийг schema linking-ээр богиносгох (~5.5k токен) эсвэл max_length ≥ 24576

   - Орчуулгын masking-ийг засах (`translate.py`: утга биш үгсийг placeholder болгодог, «байсан» г.м.).
   - Логик шалгалтын үлдсэн олдвор: dialect M1/M2/M7, L1–L8; үнэлгээний M3/M4 (тусад нь, бүх тохиргоонд).
