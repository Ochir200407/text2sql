# Орчуулгын загвар ба «тогтмол мэдлэг»-ийн Text2SQL — өөрчлөлтийн төлөвлөгөө

_Байдал: 2026-10-23. Төлөв: төлөвлөгөө v1 + өгөгдөл v0 (локал, гаднаас юу ч татаагүй). Тоонуудын эх сурвалж:
`docs/WORKLOG.md`, `results/`, `data/mt/v0/MANIFEST.json`, `scripts/mt/baseline_dev.py` (dev дээр хэмжсэн). Хэмжээгүй, тооцоолсон
тоог «тооцоо» гэж тэмдэглэв._

## 1. Товч

- **Хоёр өөрчлөлт.** (A) Орчуулгын загварыг (mn→en, en→mn) санхүүгийн хэллэг, нэр томьёогоор fine-tune хийнэ.
  (B) Text2SQL загварыг DB, компани, домэйн өөрчлөгдөхөд **өөрчлөгдөхгүй тогтмол мэдлэгээр** сургана.
- **Нэг зарчим.** Тогтмол мэдлэг → загварын жинд (fine-tune). Өөрчлөгддөг мэдлэг (схем, enum, утга, KPI тодорхойлолт,
  огноо) → prompt/RAG-д. Загвар prompt-д өгсөн мэдээллийг өөрийн «санаж буй»-аас илүүд үзэж сурна.
- **Яагаад.** Орчуулга нь dev дээрх хамгийн том алдааны шалтгаан (124 буруугийн 47, орчуулгатай асуултын зөв 23.1% vs бусад 51.2%).
  Латин галигийн орчуулга кирилл-ээс ~24 chrF++ пунктээр муу бөгөөд одоо хүртэл Text2SQL-ийн оноонд хэмжигдээгүй.
  D3 нь өөрийн DB-ийн 314 жишээгээр сургадаг тул хүснэгт/баганын нэрийг цээжилж, DB өөрчлөгдвөл эвдэрч болно.
- **Өнөөдөр хийсэн.** Төлөвлөгөө, суурь хэмжилт, өгөгдөл v0 (654 асуултын хос, 917 нэр томьёо), агентуудад өгөх заавар (§10).
- **Таны зөвшөөрөл хэрэгтэй зүйл** (гаднаас татах өгөгдөл) — §10.3.

## 2. Ойлголт ба таамаглал (асуулгүйгээр шийдсэн)

1. «Орчуулгын загвар» = Text2SQL-ийн өмнөх алхам (`pipeline/translate.py`): монгол (кирилл, латин, холимог) асуулт → англи (одоогийн
   qwen3.5-9b), мөн урвуу чиглэл en→mn (сургалтын өгөгдөл үүсгэх, монгол тайлбар/тодруулга бичих).
2. «Санхүүгийн хэллэг» = ББСБ-ийн нэр томьёо (зээл, хүү, шимтгэл, торгууль, DPD, NPL, барьцаа, батлан даагч, хорогдуулалт ...),
   тоо/огноо/дүнгийн монгол хэлбэр, англи товчлол (NPL, PAR30, KYC, AML), DB-ийн оноосон нэр.
3. «Domain хэзээ ч өөрчлөгдөхгүй тогтмол мэдлэг» = **схем, компани, DB өөрчлөгдөхөд хүчинтэй хэвээр үлдэх мэдлэг**: SQL (PostgreSQL),
   схемийг prompt-оос уншиж холбох чадвар, санхүүгийн ойлголтын логик (үлдэгдэл, DPD, PAR, хүүгийн хуримтлал ...), татгалзах/тодруулах
   зан үйл. Ard Credit-ийн өөрийн хүснэгт/баганын нэр, enum код, салбар, бүтээгдэхүүн, KPI-ийн босго нь тогтмол биш → prompt/RAG.
   _(Хэрэв «domain» гэж өөр зүйл (жишээ нь зөвхөн ББСБ-ийн домэйн) хэлсэн бол §4-ийн «тогтмол / өөрчлөгддөг» хүснэгт ба §6.1-ийг засна — бусад хэсэг өөрчлөгдөхгүй.)_
4. Text2SQL загвар **зөвхөн англи prompt**-оор ажиллана (H4/I3t-ийн шийдвэр хэвээр). Монгол хэлний мэдлэг бүхэлдээ орчуулгын
   давхаргад төвлөрнө → Text2SQL-ийн сургалтад англи нээлттэй өгөгдөл (Gretel, BIRD англи эх) ашиглах боломжтой.

агентын бичсэн жишиг хосод ч ~42% л гарсан тул **алдаатай хэмжүүр**. Одоо `scripts/mt/term_accuracy.py`: зөвхөн curated 56 нэр томьёо (glossary + lexicon), англи

(`scripts/mt/mt_metrics.py`), sacreBLEU-тэй үнэмлэхүй харьцуулахгүй — зөвхөн манай туршилтуудыг хооронд нь.

Шийдвэрийн дүрэм: M0-д дээрх 3-ыг (TranslateGemma-гүй) dev дээр zero-shot хэмжиж, **2-ыг** fine-tune хийнэ. Сонголт = dev chrF++ ба
нэр томьёоны зөв (hint-тэй) + T4 дээр найдвартай ажиллах + лиценз. M0-д мөн **одоогийн кэшээр латин асуултын I3t EX-ийг** (dev, 1 хувилбар)
хэмжиж латин талын суурийг тогтооно. **Латин замын сонголт:** (a) латин текстийг шууд fine-tune хийсэн MT; (b) `Transliterator(improved=True)` → кирилл MT
(хөрвүүлэлт өөрөө 94.8% — кирилл chrF++ 58.0-ийн ойролцоо хүрэх дээд хязгаартай, нэмэлт сургалтгүй); (c) (a) + hint-ийг (b)-ээр. M0-д (b)-г zero-shot хэмжиж (a)-тай харьцуулна.

**M0 runbook** (Colab T4 эсвэл Kaggle; `scripts/mt/m0_translate.py` — mock backend-ээр туршсан, загварын backend-ууд GPU дээр туршигдаагүй). Код + `data/mt/v0`
(`dist/t2s_code.zip`-ийг шинэчлэн багцлах эсвэл `scripts/mt/`, `src/`, `evalset/dev.jsonl`, `data/mt/v0/terms.jsonl`, `build/index/values.json`, `knowledge/`-ийг хуулна):

```bash
pip install -q transformers accelerate sentencepiece bitsandbytes
# 1) MADLAD zero-shot: латин шууд (a) ба хөрвүүлж (b)
python scripts/mt/m0_translate.py --backend hf_seq2seq --model google/madlad400-3b-mt --tag m0_madlad_a --translit none
python scripts/mt/m0_translate.py --backend hf_seq2seq --model google/madlad400-3b-mt --tag m0_madlad_b --translit improved
# 2) Qwen3.5-9B zero-shot (hint-тэй/гүй, латин (a)/(b))
python scripts/mt/m0_translate.py --backend hf_causal --model Qwen/Qwen3.5-9B --load-4bit --cudnn-off --hints lexicon --translit improved --tag m0_qwen_b
python scripts/mt/m0_translate.py --backend hf_causal --model Qwen/Qwen3.5-9B --load-4bit --cudnn-off --hints lexicon --translit none --tag m0_qwen_a
# 3) оноо: chrF++, curated нэр томьёо, утга, тоо (кирилл/латин тусад нь)
for t in m0_madlad_a m0_madlad_b m0_qwen_a m0_qwen_b; do python scripts/mt/baseline_dev.py --cache build/translations/$t.jsonl; done
```

Шийдвэр: кирилл chrF++ / curated нэр томьёо хамгийн өндөр 2 загварыг сонгоно; латин замд (a) ба (b)-ийн шилдгийг сонгоно (латин chrF++ суурь 33.9; (b)-ийн дээд хязгаар ≈ кирилл).

### 5.4 Prompt ба формат (SFT мөр)

```
system: Translate a question about a Mongolian non-bank financial institution. Direction: mn(latin)→en.
        Terms (Mongolian = English): хугацаа хэтэрсэн хоног = days past due (DPD); шимтгэл = fee
        Copy text inside «…» exactly. Output only the translation.
user:   «Дархан» салбарын хугацаа хэтэрсэн зээлийн үлдэгдэл хэд вэ?
assistant: What is the outstanding balance of overdue loans at the «Дархан» branch?
```

1. **Нэр томьёоны hint** = `translate_terms.term_hints()` (нэг эх сурвалж) — сургалтад **30% hint-гүй**, **10% хуурамч/хамааралгүй hint**
   (загвар hint-ийг сохроор хуулахгүй, асуулттай таарвал л ашигладаг болно).
2. **DB-ийн утга** `[V1]` маскийн оронд `«…»` (каноник, дагаваргүй) — загвар үгчлэн хуулна; англи гаралтад `«»` үлдэж, pipeline `"…"` болгоно.
   Маск үүсгэх дүрэм хэвээр (T2: зөвхөн яг таарсан DB-ийн оноосон нэр), гэхдээ хуурамч маск (байсан → Баасан) сургалтын өгөгдөлд **сөрөг жишээ**.
3. **Бичгийн tag**: `mn(cyrillic)`, `mn(latin)`, `mn(mixed)`, `en→mn` — нэг загвар дөрвөн чиглэлтэй.
4. **Хэлбэржилт**: «1.5 сая төгрөг» → 1.5 million MNT; «2025 оны 3-р сар» → March 2025; «30-аас дээш хоног» → more than 30 days;
   NPL/PAR30/DPD/KYC/AML/LTV/DTI хэвээр; төгрөг → MNT.
5. MADLAD-д system байхгүй → `<2en> [T: …] текст` хэлбэрээр.
6. **Латин оролтын hint**: одоо `term_hints()` кирилл түлхүүрээр хайдаг тул латин асуултад hint **0** (суурь хэмжилт). Өөрчлөлт: эхлээд
   `Transliterator(vocab, improved=True)`-аар кирилл болгож (дээд 94.8% үгийн нарийвчлал; `src/mn_text2sql/text/normalize.py`-д opt-in горим нэмсэн, анхдагч хэвээр) hint хайна;
   сургалтад ч үүнтэй ижил функцээр hint үүсгэнэ. Retrieval-ийн `to_cyrillic`-д ч ашиглах нь латин асуултын RAG-ийг сайжруулна (өөрчлөлт хүлээгдэж байна).

### 5.5 Сургалтын жор

- QLoRA/LoRA r = 32, α = 64, LR 1e-4 (QLoRA) / 2e-4 (LoRA), cosine, warmup 3%, 2–3 epoch, max_length 512, loss зөвхөн гаралтад.
  Одоо байгаа `training/sft.py` + `config/training.yaml`-ийн жор (`mt_q9b`, `mt_madlad`) нэмж ашиглана; checkpoint/deadline механизм хэвээр.
- Replay 10% (D7), en→mn 15%.
- Зардал (тооцоо, D3-ийн хэмжсэн ~1k токен/с 2×T4 хурдаас): 12 000 хос × ~150 токен ≈ 1.8 сая токен/epoch ≈ **30–40 мин/epoch**
  (Qwen 9B QLoRA), MADLAD 3B түүнээс хурдан. Нэг bake-off + fine-tune нь Kaggle-ийн нэг сессэд багтах төлөвтэй (тооцоо).
