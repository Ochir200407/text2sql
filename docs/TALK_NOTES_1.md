## Нэг. Систем юу хийдэг вэ (1 минутад ойлгох)

Ажилтан **монголоор** асуулт асууна → систем түүнийг **SQL** болгож банк бус санхүүгийн байгууллагын өгөгдлийн сангаас тоо
гаргаж өгнө. Жишээ: «Өнгөрсөн сард хэдэн зээл олгосон бэ?» → `SELECT count(*) FROM loans WHERE …` → «1 284».

Долоон алхам:

| Алхам | Юу хийдэг | Хэрэгсэл |
|---|---|---|
| 1. Шалгах | Хувийн мэдээлэл, бичих хүсэлт, хоёрдмол асуултыг илрүүлнэ | Дүрэм |
| 2. Орчуулах | Монгол (кирилл/латин) асуултыг англи хэл рүү | **MADLAD-400-3B** (санхүүгийн хэллэгээр сургасан) |
| 3. Мэдлэг хайх | Хүснэгт, нэр томьёо, DB-ийн утга, жишээ асуултыг олно | BM25 + BGE-M3 (RAG) |
| 4. SQL бичих | Англи асуулт + олсон мэдлэгээр SQL | **Arctic-Text2SQL-R1-7B** (+LoRA) |
| 5. Шалгах, засах | SQL-ийг ажиллуулж алдаа гарвал засуулна | PostgreSQL, sqlglot |
| 6. Санал хураах | 8 хувилбараас олонх нь давхцсаныг сонгоно | — |
| 7. Хариулах | Тоо, эсвэл «хариулж чадахгүй» / «тодруулна уу» | — |

Эцсийн систем (M1ens) нь энэ дамжлагын таван тохиргооны (M1rr, M1ks, M1a, M1g8, M1m) эцсийн SQL-ийг ажиллуулж, үр дүнгээр
нь дахин санал хураадаг чуулга (загвар дахин дуудахгүй).

**Гол санаа:** өөрчлөгддөггүй мэдлэг (SQL бичих, хэл) — загварын жинд; өөрчлөгддөг мэдлэг (хүснэгт, нэр томьёо, дүрэм) —
мэдлэгийн санд (RAG). Тиймээс DB өөрчлөгдөхөд загварыг дахин сургах шаардлагагүй.

## Гурав. «Та яг юу хувь нэмэр оруулсан бэ?» — 3 цэг

- **Үнэлгээний сан:** монгол хэлний анхны Text2SQL сан — 500 асуулт, 3 бичиг (кирилл, латин, англи), хариулах боломжгүй ба
  хоёрдмол асуулттай, family-аар dev/test хуваасан (давхцал 0), 8 хуулбар DB-ийн test-suite-тэй.
- **Систем:** нээлттэй загвартай, нэг GPU-д чиглэсэн, байгууллагын дотор ажиллах бүтэн дамжлага (орчуулга → RAG → 7B SQL →
  шалгалт/засвар → сонголт → Studio) ба санхүүгийн хэллэгээр сургасан MADLAD орчуулагч (chrF++ 53.5 → 74.8; Qwen 58.0).
- **Хэмжилт:** бүрэлдэхүүн бүрийн нөлөөг нэг DB дээр McNemar-аар тус тусад нь хэмжиж, батлагдаагүй үр дүнг (D2 сургалт —
  ижил нөхцөлд 82 → 81, reranker, M1g8) ч нуулгүй тайлагнасан; гол тохиргоог (чуулга) урьдчилан зарлаж, test-ийг нэг л удаа
  ашигласан; SQL-ийн бүтцийн шинжилгээгээр алдааны жинхэнэ шалтгааныг (шүүлт, агрегат, төстэй
  хүснэгт андуурах) тогтоосон.

  тусад нь шалгасан; зарим нь батлагдсан (орчуулагч p = 0.0066, 13 асуултыг хасвал 0.047, загвар төстэй 6-г ч хасвал

- **Хязгаарлалт:** өгөгдөл синтетик, ганц DB; үнэлгээний санг хүн шинжээч шалгаагүй; test ±7 хувь; хурд — нэг үүсгэлттэй
