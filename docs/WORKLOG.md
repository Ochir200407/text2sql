### 2.4 Шударга байдлын дүрэм

1. dev-ийн асуулт тус бүрд тааруулахгүй — зөвхөн ерөнхий засвар (dialect, мэдлэгийн сан, prompt, pipeline), бүх тохиргоонд

2. Test-ийн асуулт жишээний санд хэзээ ч орохгүй. dev-ийн асуултыг жишээ болгоход dev асуулт бүр өөрийн family-ийн жишээг
   татахгүй (хасахгүй бол 300-аас 227 нь өөрийн family-г татах байсан).
3. Шинэ жишээ бичих agent-уудад eval set (dev, test, drafts), `results/`, `docs/`-г уншихыг хориглосон; бичсэн жишээг
   eval-ийн аль нэг хувилбартай 3-gram cosine ≥ 0.8 эсвэл gold-той ижил үр дүнтэй бол хасна.
4. Хоёрдмол асуултад тодруулга = зөв (GUIDE.md, `metrics.trust_score`); хариулах боломжтой асуултад тодруулга = буруу.

   хоёуланг нь тайланд ил тод тэмдэглэнэ.
6. Туршилтын төлөвлөгөөнөөс хазайсан бүхнийг тайланд бичнэ (8-р хэсгийг үз).
