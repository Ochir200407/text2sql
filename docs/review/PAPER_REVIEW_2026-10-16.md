## 3. Монгол хэл ба нэр томьёо

- **З:** RQ2-ын «мэдлэгийн давхарга» → «схемийн тайлбар». «Загвар» (template) → «хэв загвар». Нэр дэвшигч SQL ба орлох gold SQL-ийг «хувилбар»-аас салгав. «Эргэн төлөлт (төлбөр)» / «барагдуулалт (collection)». «Бичгийн хувилбар» → «асуултын хувилбар». «Мөрийн түвшний хамгаалалт» болгож нэгтгэв. 30 орчим найруулгын засвар хийв.
- **Х:** Латин үгийн дагавар: gold-ийг, run-ы, McNemar-ын болгож нэгтгэв. tool-той/tool-ийн, GRPO-ийн, LoRA-ийн хэвээр (албан стандарт байхгүй).
- **Ө:** eval set / үнэлгээний сан, agent / агент гэсэн холимог хэрэглээ хэвээр (уншихад саадгүй).
