\textit{\textbf{Түлхүүр үгс: \keywordnames}}
\bigskip

Санхүүгийн байгууллагын ажилтнууд өгөгдлийн сангаас тоо мэдээ авахдаа SQL бичдэг шинжээчээс хамаардаг. Байгалийн
хэлний асуултыг SQL болгох (Text2SQL) системүүд англи хэлний Spider, BIRD жишиг дээр өндөр үр дүнтэй ч
монгол хэлэнд зориулсан систем, үнэлгээний сан, туршилтын нотолгоо бараг байхгүй. Монгол хэлний залгамал үгзүй,
кирилл ба латин галигийн холимог бичлэг, өгөгдлийн санд монголоор хадгалагдсан утга, байгууллагын дотоод нэр томьёо
(PAR30, идэвхтэй багц) нь англи хэлний аргуудыг шууд хэрэглэхэд саад болдог. Мөн өгөгдөл гадагш гарах
ёсгүй тул нэг GPU-д багтах нээлттэй эхийн загвар шаардлагатай.

Энэхүү ажлаар банк бус санхүүгийн байгууллагын (ББСБ) 28 хүснэгт бүхий PostgreSQL өгөгдлийн сан (648 205 мөр
синтетик өгөгдөл) дээр монгол асуултад хариулах Text2SQL системийг нээлттэй эхийн Arctic-Text2SQL-R1-7B загвар дээр
бүтээж, бүрэлдэхүүн бүрийн нөлөөг хяналттай туршилтаар хэмжив. Үүний тулд dev 300, test 200 асуулт бүхий монгол
үнэлгээний сан (хариулах боломжгүй ба хоёрдмол асуулттай) бэлтгэж, загварын гэр бүлээр нь давхцалгүй хуваав. Систем нь
асуултыг шалгах (хувийн мэдээлэл, бичих хүсэлтээс татгалзах), англи руу орчуулах, мэдлэг хайх (BM25 ба BGE-M3: хүснэгт, утга, нэр томьёо, жишээ), өөрийн DB-ийн RAG prompt-оор LoRA-аар
нэмж сургасан загвараар SQL үүсгэх, алдааг засах, 8 хувилбараас гүйцэтгэлийн үр дүнгээр санал хураах, итгэл багатай
үед тодруулга асуух алхмуудаас бүрдэнэ. Мөн туршилтын тохиргоог node-оор угсарч, алхам бүрийн prompt ба мэдлэгийг
харуулдаг «Text2SQL Studio» вэб хэрэгслийг хөгжүүлэв.

Нийт оноо татгалзал, тодруулгыг зөвд тооцдог тул (үргэлж тодруулдаг систем test-д 24.5\%) гол хэмжүүр нь хариулах
боломжтой EX. Dev-д нийт зөв суурь загварын 2.3\%-иас (RAG-гүй) M1a-д 53.3\% хүрэв. Шинэ асуултын test дээр dev-ээр
сонгосон тохиргооны нийт зөв (хариулах боломжтой EX) нэмэлт сургалттай суурь D2-д 21.0\% (24.5\%), орчуулга ба
засвартай H4-д 34.0\% (31.8\%), 8 хувилбар ба дүрэмтэй E4-д 45.0\% (42.4\%; dev-д дэмжлэгтэй түлхүүр үгээр нийт 43.0\%),
сургасан орчуулагчтай M1a-д 50.5\% (53.6\%), урьдчилан зарласан эцсийн систем M1ens-д 55.0\% (59.6\%) болов. Dev-д
мэдлэг хайх (+12.0 хувь) ба орчуулга (ижил кодоор +7.7) хамгийн их, өөрийн DB-ийн жишээгүй нэмэлт сургалт (+1.4) хамгийн
бага нэмэр өгсөн. E2-ийн алдааны 38\% нь орчуулгаас үүдсэн тул 2 828 хосын санхүүгийн орчуулгын өгөгдлөөр
MADLAD-400-3B-ийг нэмж сургав: test-ийн хариулах боломжтой асуултад I3t-ээс $+32/-13$ ахив ($p = 0.0066$; test-ээс
мэдээлэл авсан 13 асуултгүйгээр $p = 0.047$, загвар төстэй 6-г ч хасвал $p = 0.16$). M1a ба түүний 4 хувилбарын чуулга
M1ens нь M1a-аас $+10/-1$ ахив ($p = 0.012$; эдгээр 19 асуултгүй $p = 0.039$). Гол хувь нэмэр нь монгол хэлний
анхны Text2SQL үнэлгээний сан, бүрэлдэхүүн бүрийн нөлөөг статистик тестээр шалгасан (зарим нь батлагдаагүй)
туршилт, нэг GPU-д ажиллах давтагдахуйц систем ба судалгааны хэрэгсэл юм.
