Flow builder — товч заавар

  
Text2SQL систем асуултыг алхам алхмаар боловсруулна. Энд тэдгээр алхмыг угсарч, тохиргоог нь өөрчлөөд туршилт (experiment) болгон хадгална.

  
4 алхмаар

  
    
    
  1. Эхлэх цэг сонгох — дээд мөрийн товч (жишээ нь «Одоогийн систем») эсвэл туршилтын жагсаалтаас.
    2. 
    
  2. Алхам нэмэх / хасах — зүүн талын жагсаалтаас дарвал зөв байрандаа автоматаар орно (чирж тавьж ч болно). Хасах: node-ийг сонгоод Delete — өмнөх ба дараагийн алхам өөрөө холбогдоно.
    3. 
    
  3. Тохируулах — node дээр дарахад баруун талд параметрүүд нь монгол тайлбартайгаа гарна. ● = суурь утгаас өөрчлөгдсөн.
    4. 
    
  4. Шалгах, хадгалах — доод зүүн булангийн мөр тохиргоо зөв эсэхийг үргэлж харуулна. баруун талын 💬 Emulator-т асуулт бичиж туршина (загвартай сервер дээр SQL ба үр дүн, загваргүй бол prompt), мессеж доорх «🐞 Trace» / «🔍 Prompt·RAG» нь доод Debugger-т дэлгэрэнгүйг гаргана. «💾 Хадгалах»-аар туршилт болгоно.
    5. 
  

  
Тэмдэглэгээ

  

  
Товчлуур

  
    
    
  • Ctrl+Z буцаах, Ctrl+Y дахих, Ctrl+S хадгалах
    • 
    
  • Delete сонгосон node / сумыг устгах, F бүгдийг харуулах, ? энэ заавар
    • 
    
  • Хулганы дугуй — томруулах (Ctrl-тэй), хоосон газраас чирэх — canvas-ийг хөдөлгөх
    • 
  

  
Prompt ба RAG-ийг харах

  
    
    
  • Доод Debugger-ийн Prompt·RAG таб (зүүн цэсний 🔍): асуулт бичээд «🔍 Prompt угсрах» — загвар дуудахгүйгээр (1) асуулт хэрхэн хувирахыг, (2) мэдлэг аль файлаас хэдэн ширхэг татагдсаныг, (3) RAG-ийн олсон хүснэгт, DB-ийн утга, нэр томьёо, жишээг оноотой нь, (4) токены задаргааг, (5) загварт очих бүтэн prompt-ыг харуулна.
    • 
    
  • Prompt доторх шар = RAG/мэдлэгээс нэмэгдсэн мөр, цэнхэр = жишээ (few-shot), ногоон = асуулт.
    • 
    
  • Emulator-т асуусан асуулт бүрийн бодит prompt ба RAG-ийг мессеж доорх «🔍 Prompt·RAG»-аар харна.
    • 
  

  
Анхаарах

  
    
    
  • Кодын гүйцэтгэлийн дараалал тогтмол: node-ийн дугаар (①②…) бодит дарааллыг заана. Сумыг өөр дарааллаар холбовол анхааруулга гарна.
    • 
    
  • «Асуулт»-аас «Хариулт» хүртэлх замд ороогүй node бүдгэрч, тооцоонд орохгүй.
    • 
    
  • 🔒 тэмдэгтэй алхам (Асуулт, SQL бичигч, Хариулт) заавал байна — устгахгүй, зөвхөн тохируулна.
